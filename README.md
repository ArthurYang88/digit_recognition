## Single Digit Handwritten Number Recognition
This is a simple neural network that recognizes 28x28 pixels handwritten single digits.

`ml_code.py` consists of the machine learning code.

`train_data.txt` consists of the trained weights and biases.

`main.py consists` of loading and saving current data.

`train.py`/`clean_train.py` consists of training the model using the data from mnist.npz

`writing.py` is a simple tkinter GUI program that you can write on it.
